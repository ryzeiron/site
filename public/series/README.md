Depose ici les images des series.

Convention :
- Nom du fichier = id de la serie (ex: ev09.jpg, me01.jpg, eb01.jpg)
- Formats acceptes : jpg, jpeg, png, webp
- Dimensions conseillees : ~4:3 ou proche (affichees en contain, donc n'importe quelle forme fonctionne)

Puis dans lib/catalog.ts, sur la ligne de la serie :
  image: "/series/ev09.jpg"
