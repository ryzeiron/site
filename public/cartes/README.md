# Dossier des photos de cartes

Mets ici tes photos de cartes (formats recommandes : **.jpg**, **.png**, **.webp**).

## Exemple

1. Tu ajoutes une photo dans ce dossier, par exemple :
   `public/cartes/dracaufeu-ex-ev03.jpg`

2. Dans `lib/catalog.ts`, tu renseignes :
   ```
   image: "/cartes/dracaufeu-ex-ev03.jpg",
   ```

Le chemin commence toujours par `/cartes/` (sans `public/` devant).

## Conseils

- Nomme les fichiers sans accents ni espaces : utilise des tirets.
  `dracaufeu-ex-ev03.jpg` plutot que `Dracaufeu Ex EV03.jpg`.
- Une image de 500 a 900 pixels de large suffit pour un beau rendu.
- Pour un cadrage propre, prends ta photo sur fond uni (blanc / noir).
